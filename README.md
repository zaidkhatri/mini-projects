# Mini Projects

A collection of self-contained mini projects, each demonstrating a specific concept, technology, or engineering practice. This repository serves as a growing archive of hands-on implementations across software engineering, artificial intelligence, and computer science.

## Repository Structure

```text
mini-projects/
├── library-management-system/
├── cli-to-do-list/
├── cli-expense-tracker/
└── ...
```

Each project is independent and includes its own source code, documentation, and setup instructions.

## Goals

* Build practical, focused applications.
* Explore new technologies and engineering concepts.
* Demonstrate problem-solving through hands-on implementations.
* Continuously expand into domains such as Machine Learning, NLP, Computer Vision, Backend Development, and AI Engineering.

## Current Projects

| Project                   | Description                                                         |
| ------------------------- | ------------------------------------------------------------------- |
| Library Management System | Command-line application for managing books and library operations. |
| CLI To-Do List            | Terminal-based task management application.                         |
| CLI Expense Tracker       | Command-line expense tracking application.                          |

More projects will be added over time.
